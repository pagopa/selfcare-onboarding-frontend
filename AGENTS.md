# AGENTS.md

Guidance for AI coding agents working in `selfcare-onboarding-frontend` (React 18 + TypeScript + Vite + MUI v5). See also `.github/copilot-instructions.md` for architecture and conventions.

## Setup (required before type-check or tests)

```bash
yarn install
yarn generate   # creates src/api/generated/* and openApi/generated-* (gitignored)
```

Without `yarn generate`, `tsc` and many tests fail with missing-module errors. Requires Node >= 24 and yarn 1.

## Commands

| Task | Command |
|---|---|
| Dev server | `yarn start` |
| Type-check | `yarn tsc --noEmit` |
| Lint | `yarn lint` (`yarn lint-autofix` to fix) |
| Format | `yarn prettify` |
| Unit tests | `yarn test` |
| Single test file | `yarn vitest run src/path/to/file.test.tsx` |
| Coverage | `yarn test:coverage` |
| E2E | `yarn test:e2e:local` (needs a running app and `.env.development.local`) |

## Definition of done

1. `yarn tsc --noEmit` passes.
2. `yarn lint` passes with no new warnings.
3. Relevant tests pass (run targeted files, not the full suite, unless needed); add or update tests for changed behavior.
4. User-facing strings are added to **all** locale files in `src/locale` (`it`, `en`, `fr`, `de`, `sl`).

## Do not edit

- `src/api/generated/**`, `openApi/generated-*` – regenerated by `yarn generate`. To change generated output, edit the specs in `openApi/*.json` or the fix scripts in `openApi/scripts/`.
- `.env*` secrets, `coverage/`, `dist/`, `build/`, `node_modules/`.
- `.claude/settings.local.json` – personal, gitignored.

## Gotchas

- Unit tests (jsdom + MUI) are CPU-heavy and have long timeouts; prefer running individual files.
- `VITE_MOCK_API=true` switches the app to mock behavior (see `isMockEnvironment()` in `src/utils/institutionTypeUtils.ts`).
- Routing uses React Router v5 (`Switch`, `useHistory`); do not use v6 APIs.
- Prettier: 100 cols, single quotes, semicolons, trailing commas `es5`.
